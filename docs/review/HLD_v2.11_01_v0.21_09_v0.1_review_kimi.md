## 任务 B：HLD v2.11 D23 四项补充

1. **按命中片段分类会否放过真实 PHP**：不会。片段分类只确认命中字符串/注释是检测签名或期望值；真实 PHP 文件必然命中后缀、shebang、可执行位、包元数据中的非免除信号；伪装 `.py` 的 PHP 源其 `<?php` 是裸代码而非字符串常量/注释，无法确认分类 → 仍拒绝（§11.3 有对应用例）。且全系统不允许 PHP 解释器存在，被豁免的文本无执行路径。
2. **镜像与主机按扫描器文件 digest 免除**：可执行——digest 随策略版本发布，扫描时做集合成员判定；规则表被改动即 digest 失配 → 失败（有用例）。规范文档/合成清单进入镜像即按文本信号判定，无免扫通道。
3. **"调用"按声明 + E0 子进程观测**：口径可机械执行（声明路径 → 包数据库闭包 → E0 观测补全），但有一个残余漏洞，见 H211-01（MINOR）。
4. **current_digest 从当前实际状态重算**：可执行——采集来源（包数据库重新解析、安装前缀文件树重算）、禁止复制旧记录、独立构建主机一并比对、相等且例外未过期才创建 Run，均为确定性操作；"可信的部署侧"与 D13 内网单机信任模型一致。
5. **例外双处比对**：无歧义——条目含批准它的 HLD 版本，门禁比对门禁清单与该版本 D23 表两处，"任一缺失、不一致或已到期即视为无例外"；当前表为"无"，基线干净。

## 任务 C：01 v0.21 核对

1. **人工裁决剩余路径**：要把一个实际已发布的任务判成 confirm_not_released，现在需要同时满足：本授权无任何已落账 confirmed_happened（否则被规则①挡住）、无部分出现记录、裁决前的强制探测失败或未检出、至少一条远端证据、原 holder 静默。发布只能发生在核销后的唯一执行许可上；若执行实际完成，强制探测（成功时）必然检出 → 只能 confirm_released。探测失败进入 unknown 时，远端证据须由运维提供的外部系统记录充当——此时远端实际已发布而记录称未发布，属于人提供虚假/陈旧证据，超出契约可防范围，且有 post_close_correction 兜底。①–⑤与类型化证据叠加后，**未发现契约层可进一步消除的误判路径**。"暂停时按 unknown"与"强制探测照常执行"的旧矛盾已消除（K3 与 §5.1 措辞一致：暂停只禁自动派发）。
2. **K2 在任意归因策略下的有界性**：Codex 的循环反例（probe ACK 后永不报告 → 反复排空换实例）现在每次 isolation_drain 对快照并集（含该 probe task）计 affected → max_task_affected 次后 manual_only + auto_probe_suspended，循环终止；isolation_drain 限空执行快照挡住"替换策略在执行中反复回收"的口子；retire_requested 同理计数；planned_restart 是运维行为、由人控制节奏。加上任务域事件（v0.20 已证有界），**所有自动发起的事件源都在 K2 之下**。"自动路径上界"与"运维强制探测可超出但须显式发起"两处表述一致（K2 与 CF-AUTH-20q 相同措辞）。
3. **K4 ③ 期限停滞暂停**：唤醒 = 人工恢复或一次正常结案（已核销 task 的恢复/对账/只探测不受暂停影响，故正常结案仍可能发生，唤醒来源真实存在）；暂停期间授权到期按可见原因关闭；暂缓经 K5 有持久化唤醒；dispatch_paused 持久化于 CrossTaskBreaker，重启保留。无饿死（暂停本身是可见状态且告警入 R13）、无绕过（新 execute 一律经统一入口写 intent 暂缓，放行复核含暂停条件——K5 作废段把"暂停条件"列为保持暂缓而非作废的原因，语义正确）。隔离头在暂停期间无法放行执行属于预期行为（暂停即停止新执行），其预约由 K5 活性条款与授权过期兜底，不构成死锁。
4. **K5 放行/作废/预约释放**：放行复核的结局二分清晰——守卫/模式/暂停/通道许可类原因保持暂缓（有唤醒来源），其余不满足即在放行事务内作废（superseded 指向本次复核，不占 token 名额，条件恢复后发送点重建）；reservation_seq 使同 task 同 epoch 两次当选可区分，旧通知 CAS 失败不释放新预约（CF-AUTH-20k 新增对应格）。每格恰一个出口。
5. **正文残留策略依赖/保证**：持有者更替重派与 recovery_mode 迁移已改通用表述；K5 以"任何使其他派发暂缓的独占预约"泛化；S1–S3 与 CF-STR 表维持"非规范/目标与度量"标注。**未发现残留**。
